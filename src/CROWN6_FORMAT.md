# CROWN6 Stream Format (v1) — byte-level spec

Single exact bit-level codec file set: `src/crown6.c` (streaming channel
decoder + RCT inverse + Golomb packer + MLP batch-predict entry) +
`src/driver_crown6.py` (Python encoder/trainer, assembly, C-decode calls) +
`src/crown6_tanhlut.h` (frozen tanh LUT, generated by `src/gen_tanhlut.py`) +
per-image weight caches `experiments/crown6_weights/crown6_<img>.npz`.
Linked read-only: `src/libhapre.so` (`pack_syms`, `rans_norm/encode/slots/decode`
— all verified wire-compatible; its `golomb_pack` unary variant is NOT used,
see below). `libcrown6.so` is built from `crown6.c` alone
(`gcc -O2 -fPIC -shared -ffp-contract=off`). No existing file modified.

CROWN6 = CROWN4 line + per-context micro-MLP 20th expert (predid 19):
per-energy-quantile 12feat→8→1 tanh MLPs (probe_b21 committed config: L1 loss,
LS-init, 200 iters @ lr 0.003, adaptive-int16 scales {256…4096}, double MDL
gate), one gated assembly per channel competing inside the per-group exact
search. Q-family searches E20 (E16+WAVG+LMS5_T0+LMS5_T3+MLP); GRID-family
searches E18 (E17+MLP). Per-channel dual-track exact-byte gate (MLP-variant
vs no-MLP-variant, strict `<` for MLP) + Q-vs-GRID exact bytes + global RCT
min-over-{C6,C27,C12}. Bytes are therefore ≤ CROWN4 per image by construction
(extra expert can only lower the per-group min; unused MLP costs 3 flag bytes).

All integers little-endian unless noted. Bit-packed fields are MSB-first
(`BitWriter.put`: accumulator shifted left, flushed high-bit-first — identical
to `driver_crown4.py` map packing and `canon_tables` code emission).

## Constraints

- Image: H ≥ 2, W ≥ 2 (inherited; Kodak scope unaffected).
- Residual alphabet: |r| ≤ 1024 everywhere; encoder asserts loudly, decoder
  returns -4. Never clipped.
- Entropy groups per channel ng ≤ 64 (WIDE-K max 64; GRID fixed 6).
- Weighted spatial groups: GS = 32 fixed (no size selector; CROWN4 parity).
  ng32 = ceil(H/32)·ceil(W/32); block index b = (i>>5)·nbw + (j>>5).
- Predictor ids 0..19 fit the 5-bit field (values 20..31 never emitted;
  decoder rejects predid > 19 with -5; predid 19 with mlp_present==0 → -5).

## Global header (8 bytes, MAGIC DIFFERS from CROWN4)

| bytes | content |
|---|---|
| 0–1 | magic `C` `6` (CROWN4 used `C4`) |
| 2–3 | H u16le |
| 4–5 | W u16le |
| 6 | version u8 (=1) |
| 7 | flags u8, bits[1:0] = RCT id (0=C6 `(perm0,t6)`, 1=C27 `(perm3,t6)`, 2=C12 `(perm1,t5)`); bits[7:2] reserved 0 |

## Channel blob (×3, order p0, p1, p2 of the selected RCT)

### Channel header (3 bytes: CROWN4 2 bytes + 1 NEW MLP flag byte)

- byte0: `[kidx:4][grid:3][fam:1]` — fam 0 = quantile (Q), 1 = energy-grid (GRID);
  kidx = index into WIDE=(2,3,4,6,9,12,18,27,36,48,64), 15 if GRID;
  grid = M-THR selector 0..7 (valid iff GRID).
- byte1: ng u8 (1..64; 6 for GRID).
- byte2: MLP flags: bit0 = mlp_present (1 iff MLP side info follows AND predid
  19 may appear); bits[7:1] reserved 0. If 0: no MLP bytes; decoder asserts on
  predid 19.

### MLP side info (NEW; present iff mlp_present==1)

| bytes | content |
|---|---|
| 64 | energy thresholds: 8 × float64le (quantile edges of E, see below) |
| 9 | per-ctx scale ids u8: index into SCALES=(256,512,1024,2048,4096), or 255 = ctx absent (lost L1 gate or <100 samples: fixed edge-MED, no weights) |
| 226 × nwin | winning nets in ctx order 0..8: 113 × int16le, layout `[fc1.weight 8×12 row-major (96)][fc1.bias (8)][fc2.weight 1×8 (8)][fc2.bias (1)]`, each = round(true_weight × S) |

At least one ctx wins when mlp_present==1 (decoder asserts nwin > 0).
Dequantization (both sides): w = int16 / S, S a power of two → EXACT in
binary float64, no precision loss at the handoff.

### W-side (CROWN4-identical, follows MLP side)

- `ceil(ng32/8)` bytes: use flags, 1 bit per G32 block in index order, MSB-first.
- `ceil(nused·20/8)` bytes: weights for used blocks in index order, 4 taps
  w0..w3, 5 bits each MSB-first (stored `w&31`, signed `v≥16 ? v−32 : v`).

### LMS-side: ZERO bytes (CROWN4 parity; states re-simulated from recon)

### Group map (CROWN4-identical)

- Q: 92-byte dense bitmask (`np.packbits` of 729-bit active-key vector) +
  `ceil(active·gbits/8)` bytes of group ids in ascending key order.
- GRID: 1-byte occupancy mask `occ`.

### Per-group metadata (group order 0..ng−1; SAME 7-bit WIDTH as CROWN4)

1. `ceil(ng·7/8)` bytes, 7 bits/group MSB-first: `[predid:5][backend:2]`.
   predid = E20 index (0 MED … 15 AVG3, 16 WAVG, 17 LMS5_T0, 18 LMS5_T3,
   **19 MLP**); backend 0=Huffman, 1=Golomb, 2=rANS.
   Empty groups forced to backend 0 with no table/payload.
2. kvals: 4 bits per G-group (backend==1), group order, MSB-first. k ∈ 0..12.
3. dbias: 3 bits per G-group, two's-complement {−4..3} (stored `v&7`), group
   order, MSB-first. Transmitted value `t = v−d`; decoder adds back.

### Huffman tables / payloads, Golomb payload, rANS groups (CROWN4-identical)

- Per H non-empty group: `A u16le` + A × (`sym i16le` + `len u8`).
- H payload: `n u32le` + n bytes via `pack_syms` (libhapre.so).
- G payload: `n u32le` + n bytes via `crown6_golomb_pack` (crown4-verbatim).
- rANS groups (M=14): `count u32le` + `A u16le` + A × (`sym i16le` +
  `freq u16le`) + `paylen u32le` + payload, via libhapre.so `rans_*`.

## UNARY POLARITY (wire — explicit, CROWN4-identical)

- Mapping `M = v≥0 ? 2v : −2v−1`; code = **q ZERO bits, one `1`, then the
  k-bit remainder MSB-first**. libhapre.so's `golomb_pack` emits the opposite
  polarity and is NEVER called for G payloads.

## MLP wire forward (exact spec; encoder numpy == decoder C bit-for-bit)

Inputs: 12 int32 edge-features x[12] (below); weights dequantized to float64.
Order is FIXED (any reordering breaks bit-identity):
```
pre[j] = b1[j];  for i in 0..11: pre[j] += (x[i]/128.0) * W1[j][i]
rr = |pre[j]| * 16384.0          (exact: power-of-two scale)
if rr > 131072.0: h[j] = sign ? -1.0 : +1.0
else: idx = floor(rr + 0.5);  h[j] = sign * C6_TANH[idx]
     where sign = (pre[j] < 0.0) ? -1.0 : +1.0, T[i] = tanh(i/16384) frozen
y = b2;  for j in 0..7: y += W2[j] * h[j]
pred = floor(y * 128.0 + 0.5)    (half-up)
```
C is built with `-ffp-contract=off` (no FMA contraction across the mul/add
pairs, matching numpy's separate elementwise ufuncs). The frozen LUT
(`crown6_tanhlut.h`, 131073 entries on [0,8] at step 2^-14, `%.17g` literals
that parse back bit-exactly) resolves the mandated-cross-check finding that
numpy's vectorized tanh and C libm tanh differ by 1 ulp on some inputs
(e.g. pre=19.0612793 → 1.0 vs 1−2^-53), which flipped int-rounded outputs at
knife-edge .5 boundaries. Identical constants on both sides ⇒ h bits identical
by construction; the exhaustive C-vs-wire xcheck (all wire-evaluated pixels,
all images/RCTs/channels) requires 0 mismatches before integration.
Residual LUT input quantization (≤2^-15) perturbs outputs ~1e-3 gray vs torch;
gates and group search use this same path on both sides, so all MDL decisions
are self-consistent; measured torch-vs-wire int disagreement ≈1% pixels ±1 LSB
(≈+0.04% bits, documented in driver xcheck output — training is unaffected).

## MLP contexts + features (causal zero-border taps, encoder==decoder)

- Taps (ZERO border: `tap(di,dj) = plane[i+di][j+dj]` if inside, else 0 —
  exactly numpy `pad(mode="constant")` slicing; NOT probe_b21's
  edge-replication, which peeks at UNDECODED pixels on row 0 / col 0 and broke
  streaming decode at pixel (0,0) — causality bug-class, deviation [D6]):
  L=(0,−1) T=(−1,0) TL=(−1,−1) TR=(−1,+1) Ww=(0,−2) NNe=(−2,0)
  L3=(0,−3) T3=(−3,0) TL2=(−2,−2) TR2=(−2,+2).
  Interior pixels are bit-identical to the probe; only border taps differ.
- x = [L,T,TL,TR,Ww,NNe,(L+T)//2,|L−T|,L3,T3,TL2,TR2]; `(L+T)//2` is FLOOR
  division (C `c6_fdiv`, matches numpy `//` on negatives).
- Energy E = |L−T|+|L−TL|+|T−TL| (ints); ctx = #{thr[t] < (double)E} over the
  8 transmitted float64 thresholds (== numpy `searchsorted` side='left').
- Non-winning ctx (scale id 255) ⇒ edge-MED(L,T,TL) prediction.
- All taps causal (rows < i fully decoded; row i only cols < j) ⇒ streaming
  decoder reproduces encoder features exactly (proven by all-7 round-trips).

## Decoder data flow (per channel)

Parse headers → mlp_present? thresholds/scale-ids/weights (dequantized to
float64 on load) → W-side → `cmap[729]` (Q) or `grid_thr[5]` (GRID) →
predid/backend/kvals/dbias/hasn arrays (predid ≤ 19 asserted; 19 without
mlp_present returns -5) → canonical codes / rANS pre-decode → ONE C call
`crown6_decode_ch` (single causal scan; MLP forward evaluated only for
predid-19 pixels with winning ctx, else edge-MED) → `crown6_rct_inv`.
Final `p == len(blob)` asserted (exact framing); `decode == original`
byte-compared by the driver.

## Border conventions (encoder == decoder; dual-doctrine audit)

- E16 neighborhoods / LOCO-365 keys / GRID energy / WAVG stencil / LMS taps:
  CROWN4-verbatim (b4_b doctrine for E16/keys/GRID; B17-style zero-TL for
  WAVG/LMS; see CROWN4_FORMAT.md). Untouched.
- MLP features/energy/MED-fallback: zero-border causal taps above (deviation
  [D6]; probe's edge-replication peeked at undecoded pixels).
  The two doctrines coexist (different experts); each matches its training
  reference exactly (b4 paths verified since CROWN2; causal-MLP path proven by
  the C-vs-wire xcheck + all-7 byte round-trips).

## Training config (probe_b21 committed, deviations logged in driver)

12feat→8→1, L1 minibatch (bs 16384), LS-init (first-8 passthrough, Adam
recruits lag taps), 200 iters @ lr 0.003 cosine, adaptive-int16
(largest S ∈ {256…4096} with max|w|·S ≤ 32767, +3-bit id folded into the
scale-id byte), double MDL gate (L1 per-(ch,ctx) quantized-vs-MED subset
Huffman; L2 per-channel assembly+side vs MED), skip ctx with <100 samples.
Deviations [D1..D6] (RCT planes not YCoCg-R; per-unit seeding; wire-forward
gates; float64 thresholds; id 19 keeping WAVG/LMS; causal zero-border MLP
features): see driver docstring.
