## 5. C++ encoder bugs fixed 2026-09-10 pm (both pre-existing, both masked on test-7)
- Bug A — `cpp/codec.cpp` lstsq4 aborted (`CHECK`) on exact-zero pivots
  (rank-deficient G32 blocks, e.g. kodim15/C12/ch0 flat areas). Fix: degenerate-
  direction fallback mirroring `crown_train.cpp` solve13 [T3] (skip-and-zero
  with identical trigger condition, so previously-passing blocks are
  bit-identical). Without it kodim15 cannot encode at all.
- Bug B — `cpp/crown_enc.cpp` Q-family assembly used LMS *predictions* as
  *residuals* (`r = lms0_res[n]`; `lms_pred_plane` returns predictions, cf.
  Python `wch["lms0"] = ch - lms0`). Fix: `r = ch[n] - lms0_pred[n]` (and T3),
  params renamed. Masked on test-7 because no test-7 winner selects Q+LMS
  (kodim23/crop256 winners are all-GRID: no predid 17/18 anywhere); kodim15
  ch2 (Q, LMS0 group) exposed it as Golomb overrun at group 30.
- Validation: kodim15 416939 B byte-identical to Python reference;
  crop256 restored to banked 66728 B / 2.7152 (was 69583 pre-fix);
  kodim23 restored to banked 403508 B / 2.7364638 (was 419637 pre-fix);
  full test-7 battery re-run (see full7.log).
